# Roadmap

## About

This file describes plans for project development.

## Project Roadmap

This table describes more or less specific plans for development:

| Task                                                                | Description                                                                                                                                                                                                                                                                                                                                             | Status      |
|---------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------|
| Add Authentication Page and authentication redirection.             | Authentication Page should be responsible for user registration and accessing main application. This page must use backend API for registration and token issuance. For current implementation storing access token in local storage should be enough. If authentication is required, application should redirect to Authentication Page automatically. | Done        |
| Add Boards Page                                                     | Boards Page should display all user boards and their inner elements. This page must use backend API for managing board elements.                                                                                                                                                                                                                        | Done        |
| Commit 0.1.0 version                                                | 0.1.0 version denotes more or less finished prototype version. When 0.1.0 version is reached, last commit will be tagged.                                                                                                                                                                                                                               | Done        |
| Migrate to new Tracking API                                         | Backend API was updated. Frontend application should support these changes, including renamed API routes and object attributes.                                                                                                                                                                                                                         | Done        |
| Improve project foundation: UI layout, project structure, redirects | As basic functionality was implemented, now better practices may be used. Implementing common layouts and redirects would improve application code, and updated project structure should make project easier to use.                                                                                                                                    | Done        |
| Commit 0.2.0 version                                                | 0.2.0 version denotes version supporting reimagined API for Tracking.                                                                                                                                                                                                                                                                                   | Done        |
| Migrate to Angular Material and Tailwind CSS                        | Existing component libraries simplify development.                                                                                                                                                                                                                                                                                                      | In Progress |
| Fix UI layout responsiveness for Boards and Cards                   | In previous version layout worked correctly in cases when there is too many columns, but currently this behaviour is not implemented for new UI.                                                                                                                                                                                                        | Planned     |
| Commit 0.3.0 version                                                | 0.3.0 version denotes first version implemented with Angular Material and Tailwind CSS.                                                                                                                                                                                                                                                                 | Planned     |

## Future Ideas

This table describes less specific plans for future development. These plans have higher chance to be dropped or to be totally reworked:

| Task                                             | Description                                                                                                                                                                       | Status  |
|--------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------|
| Improve version history and add migration guides | For `0.x.x` versions no migration guides were provided, making updating inconvenient. Although it is not critical, it would improve project quality if such guides were provided. | TBD     |
| Improve observability                            | Metrics are already collected, but observability presents more opportunities. Observability process should be set up to collect, store and process logs, traces and metrics.      | TBD     |
| Improve UI message display                       | Currently, application is not very user friendly. "Toasts" and other message elements should be added.                                                                            | TBD     |
| Implement Home Page                              | Home Page was not designed yet, but it would be better to find a good idea for it.                                                                                                | TBD     |
| Add user profile access                          | When backend API provides such functionality, UI should implement viewing and updating user data.                                                                                 | TBD     |
| Add custom theme                                 | Angular Material provides access to setting own theme. New theme with design should make UI better. This includes light and dark themes.                                          | TBD     |
